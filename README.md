# Cricket-Performance-Analyst-System

## Overview
A computer vision based cricket analytics system that detects and tracks players from match footage and generates performance metrics.

## Features
- Player Detection using YOLO
- Multi-Object Tracking
- Distance Covered Calculation
- Average Speed Estimation
- Time on Field Analysis
- CSV Analytics Export

## Tech Stack
- Python
- OpenCV
- YOLO
- Roboflow
- NumPy
- Pandas
- Google Colab

## Results
- Trained custom cricket object detection model
- Achieved 68% mAP@50
- Processed real match videos
- Generated player movement analytics
